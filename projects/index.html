NetShape

dev tool · pypilive ↗

Simulate bad networks for any app, without touching its code.

Wraps any process in a local HTTP/HTTPS forward proxy that injects bandwidth caps, latency, packet loss and jitter. Token-bucket throttling on asyncio, 12 profiles from 2G to fiber, live adjustment without restarts, per-endpoint regex rules, and YAML scenarios like 4G → dead zone → 2G. It also ships a built-in dashboard streamed over SSE.
